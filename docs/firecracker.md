# lgbox firecracker backend (host only)

`lgbox serve --backend firecracker` grades each job inside a pool of Firecracker
microVMs restored from one shared snapshot. This sandbox has no /dev/kvm (rule 4);
the pool logic is tested with a `FakeVmm` (`lgbox/tests/firecracker.rs`) and the
VM config generator is checked by `--dry-run`. Everything below runs on Kevin's
host.

## What lgbox does at runtime

- Spawns `--vm-size` (default: `--workers`) `firecracker` processes, one per pool
  slot. Slot *i* gets `guest_cid = <base> + i` (base 3) and its vsock UDS at
  `/tmp/lgbox-fc-<cid>.sock`; the firecracker API socket is the same path + `-api`.
- Each boot is `PUT /snapshot/load` (`resume_vm: true`) against that API socket —
  no kernel boot, ~0.6 s per VM.
- Jobs lease a VM round-robin, block (queue) when all slots are busy, then:
  `put` files -> `exec` -> `get` outputs -> `reset`. Any error marks the slot
  dead; the next lease re-boots it from the snapshot. A failed `reset` keeps the
  job's result but also re-boots the VM on the next lease.
- VM config (machine-config / boot-source / drives / vsock / snapshot-load) is
  generated by `lgbox serve --backend firecracker --dry-run`. Field names follow
  the firecracker main-branch API.

## Host prerequisites

- `/dev/kvm` (the user running lgbox must have access).
- `firecracker` binary; point `LGBOX_FIRECRACKER_BIN` at it (default: `firecracker`
  on PATH).
- Files under `/var/lib/lgbox/`:
  - `vmlinux` — guest kernel (below)
  - `rootfs.ext4` — guest rootfs (below)
  - `snapshot.vmstate` + `snapshot.mem` — snapshot pair (below)

## 1. Guest kernel

Build a minimal kernel with virtio-blk and vsock:

```
CONFIG_VIRTIO_BLK=y
CONFIG_VIRTIO_CONSOLE=y        # optional, for the ttyS0 console
CONFIG_VSOCKETS=y
CONFIG_VIRTIO_VSOCKETS=y
```

Boot args used by lgbox: `console=ttyS0 reboot=k panic=1 pci=off`.

## 2. Guest rootfs

Any minimal Linux rootfs (e.g. a `debootstrap`/alpine ext4 image). It needs:

- an `/init` (or systemd) that mounts `/proc`, `/sys`, then starts the guest
  agent **before the VM is paused for the snapshot** (step 3);
- a writable workdir `/work` — `put` writes under it, `exec` runs with cwd
  `/work`, `get` reads from it, `reset` wipes it;
- the guest agent (step 3).

## 3. Guest agent (vsock port 52, JSON lines)

One line in, one line out per operation; the agent replies `{"ok":true}` unless
the op failed:

| op | request | reply |
|----|---------|-------|
| put | `{"op":"put","files":{path:content}}` | `{"ok":true}` |
| exec | `{"op":"exec","cmd":[...],"timeout_s":N}` | `{"exit_code":N,"timed_out":b,"stdout":"...","stderr":"..."}` |
| get | `{"op":"get","paths":[...]}` | `{"files":{path:content\|null}}` |
| reset | `{"op":"reset"}` | `{"ok":true}` |

Reference agent (Python 3; `socket.AF_VSOCK` is port 52):

```python
import json, os, signal, socket, subprocess

WORK = "/work"

def run(cmd, timeout_s):
    def term(s, f):
        raise TimeoutError
    signal.signal(signal.SIGALRM, term)
    signal.setitimer(signal.ITIMER_REAL, timeout_s)
    try:
        p = subprocess.run(cmd, cwd=WORK, capture_output=True, text=True)
        return {"exit_code": p.returncode, "timed_out": False,
                "stdout": p.stdout[-4096:], "stderr": p.stderr[-4096:]}
    except TimeoutError:
        return {"exit_code": None, "timed_out": True, "stdout": "", "stderr": "timeout"}
    finally:
        signal.setitimer(signal.ITIMER_REAL, 0)

def handle(req):
    op = req["op"]
    if op == "put":
        for p, c in req["files"].items():
            fp = os.path.join(WORK, p)
            os.makedirs(os.path.dirname(fp), exist_ok=True)
            with open(fp, "w") as f: f.write(c)
        return {"ok": True}
    if op == "exec":
        return run(req["cmd"], req["timeout_s"])
    if op == "get":
        files = {}
        for p in req["paths"]:
            try: files[p] = open(os.path.join(WORK, p)).read()
            except OSError: files[p] = None
        return {"files": files}
    if op == "reset":
        for e in os.listdir(WORK):
            fp = os.path.join(WORK, e)
            (os.rmdir if os.path.isdir(fp) and not os.path.islink(fp)
             else os.remove)(fp)
        return {"ok": True}
    return {"ok": False}

s = socket.socket(socket.AF_VSOCK, socket.SOCK_STREAM)
s.bind((socket.VMADDR_CID_ANY, 52))
s.listen(16)
while True:
    c, _ = s.accept()
    for line in c.makefile():
        line = line.strip()
        if line:
            c.sendall((json.dumps(handle(json.loads(line))) + "\n").encode())
    c.close()
```

Run it from `/init` (e.g. `exec /usr/bin/python3 /agent.py`).

## 4. Create the snapshot (one time, host)

Start a *source* VM from boot (not from the snapshot) with the same
machine-config/boot-source/drives/vsock that `--dry-run` prints, wait until the
agent answers, then pause and freeze:

```sh
export FC=/tmp/fc-src.sock
firecracker --api-sock "$FC" &
curl -s "$FC" -X PUT -H 'Content-Type: application/json' \
  -d '{"vcpu_count":1,"mem_size_mib":512,"smt":false}' $FC/machine-config
curl -s "$FC" -X PUT -d '{"kernel_image_path":"/var/lib/lgbox/vmlinux","boot_args":"console=ttyS0 reboot=k panic=1 pci=off"}' $FC/boot-source
curl -s "$FC" -X PUT -d '{"drive_id":"rootfs","path_on_host":"/var/lib/lgbox/rootfs.ext4","is_root_device":true,"is_read_only":false}' $FC/drives/rootfs
curl -s "$FC" -X PUT -d '{"guest_cid":3,"uds_path":"/tmp/fc-src-vsock.sock"}' $FC/vsock
curl -s "$FC" -X PUT -d '{"action_type":"InstanceStart"}' $FC/actions
# wait until the agent answers (python3 -c 'import socket; ... AF_VSOCK connect(3,52)')
curl -s "$FC" -X PUT -d '{"action_type":"InstancePause"}' $FC/actions
curl -s "$FC" -X PUT -d '{"snapshot_path":"/var/lib/lgbox/snapshot.vmstate","mem_file_path":"/var/lib/lgbox/snapshot.mem","diff":false}' $FC/snapshot/create
kill %1
```

Note the `mem_size_mib`/`vcpu_count` at restore must match the snapshot; lgbox
restores with the same `--vcpu`/`--mem-mib` flags you used here.

## 5. Run (host)

```sh
export LGBOX_FIRECRACKER_BIN=/usr/local/bin/firecracker
lgbox serve --backend firecracker --port 7777 --workers 4 --vm-size 4 \
  --kernel /var/lib/lgbox/vmlinux --rootfs /var/lib/lgbox/rootfs.ext4 \
  --snapshot /var/lib/lgbox/snapshot.vmstate --mem-file /var/lib/lgbox/snapshot.mem \
  --vcpu 1 --mem-mib 512
```

`lgbox serve --backend firecracker --dry-run --vcpu 1 --mem-mib 512 ...` prints
the exact API config without starting anything (used by the acceptance test).
